Core Platform Components
Detailed engineering breakdown of all 9 core security subsystems

6.1 SIEM — Security Information & Event Management

The SIEM module handles log collection, parsing, correlation, and long-term retention across all connected data sources.

  • Log Collection & Ingestion: Supports Syslog (UDP/TCP/TLS), SNMP, WMI, Windows Event Forwarding, REST API webhooks, and agent-based streaming.
  • Parsing & Normalization: Maps raw logs to Elastic Common Schema (ECS). Automatically extracts fields like source.ip, user.name, process.command_line.
  • Event Correlation Engine: Evaluates events against 400+ built-in correlation rules across multi-event sliding time windows.
  • Search & Investigation: Full-text indexing with regex filtering, timeline reconstruction, and query optimization for multi-gigabyte log datasets.
  • Storage & Retention: Hot storage in MongoDB time-series collections with automatic TTL indexing for 365+ day compliance retention.
  • AI Engine Integration: Ingested normalized streams are evaluated in parallel by the AI Anomaly Detection Engine to enrich events with confidence scores.

7.2 Web & Application Attack Defense Details

The AJNAT WAF inspects Layer-7 HTTP/HTTPS traffic in real time. Incoming requests pass through an Array of Pattern Evaluators: 

// Sample WAF Payload Inspection Logic (AJNAT WAF Engine v3.0)
function inspectPayload(payload) {
  if (PATTERNS.SQL_INJECTION.some(regex => regex.test(payload))) {
    return { blocked: true, attackType: 'SQL_INJECTION', score: 75 };
  }
  if (PATTERNS.XSS.some(regex => regex.test(payload))) {
    return { blocked: true, attackType: 'XSS', score: 75 };
  }
  if (PATTERNS.COMMAND_INJECTION.some(regex => regex.test(payload))) {
    return { blocked: true, attackType: 'COMMAND_INJECTION', score: 75 };
  }
  return { blocked: false, score: 0 };
}
